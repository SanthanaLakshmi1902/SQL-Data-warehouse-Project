# SQL-Data-warehouse-Project
Creating data warehouse with SQL server including ETL process, data modeling and analytics 

This project demonstrates the design and implementation of an end-to-end
data warehouse using the **Medallion Architecture**.

The project integrates data from two source systems:

- **ERP (Enterprise Resource Planning)**
- **CRM (Customer Relationship Management)**

The source data is provided as CSV files. The data is ingested using a
**full-load approach**, cleaned and transformed through different layers,
and ultimately prepared for **data analysis, reporting, and BI**.

The project focuses on building a structured and reliable data pipeline
that transforms raw operational data into analytics-ready information.

---
The project covers the following areas:

- Extract data from ERP and CRM CSV files
- Perform full-load data ingestion
- Store and organize raw source data
- Clean and validate the source data
- Handle missing, duplicate, and inconsistent data
- Standardize data formats and values
- Transform data into business-friendly structures
- Build a data warehouse using Medallion Architecture
- Create analytical datasets for reporting
- Perform data analysis
- Generate business insights and reports
